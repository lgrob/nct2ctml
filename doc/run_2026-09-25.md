## Inputs

  - **Reviewed copies:** the 55 reviewed trials in `ctml/reviewed` take precedence over their new mapped copies, as designed.

## Defects found by the run
1. **String tool answers** (`6de4430`, `9d7ed31`). 7 of 11,959 answers came back as a string, because the model's tool input was not valid JSON. The string reached the mapper, which raised, and the trial wrote no output at all: 4 trials in wave 1.
   - **Fault types:** in 6 answers the only fault was a missing closing brace; in 1 (NCT07662369) a complete object was followed by stray tool-call markup.
   - **Fix:** `decode_tool_result` now decodes both cases. `keep_candidates` turns any malformed result into "no diagnosis" instead of raising. All 7 answers now decode (11-21 diagnoses each).
2. **An empty diagnosis list was published** (`9d7ed31`). Routing only checked that `oncotree_primary_diagnosis` was present, so `[]` went to `mapped`, where it would match every patient. Seen on NCT04879121 and NCT07662369. Routing now requires a non-empty diagnosis. With the fix, 5 basket/pan-tumour trials that got no diagnosis moved to review: NCT04566380, NCT04879121, NCT05491525, NCT06119789, NCT06904235.
3. **A record without arm groups** (`2104df7`). NCT06383338 has interventions but no `armGroups`, and the KeyError lost the trial before any model call. It is the only such record in the cache.
