### Run
68 chunks of 15-16 trials, at most 12 in parallel, 4 calls at a time each.
3,583 answered calls, 0 failed. Earlier answers were reused where a prompt was
unchanged. About $26 at list price without caching.

A first attempt the same morning was discarded without being applied: at 68
parallel chunks x 8 calls, 2,049 of 2,812 calls failed, and the harness
cached each failure as an empty answer, so trials were mapped from gaps (158
trials without any diagnosis). The harness now never caches a failure,
retries with back-off and reports an unanswered trial as not done.

### Integration (recall first)
A re-mapped trial is published only if every patient code it loses against
its previous version comes from a diagnosis named only in the exclusions.
73 trials lose other codes (mostly secondary diagnoses: Burkitt, Hodgkin, NET
subtypes); they go to review with `remap_dropped_diagnoses` and the previous
version kept as `.yaml.prev`. Previous copies in both layers are backed up
before being replaced.

| | trials |
|---|---|
| published (mapped) | 911 |
| review queue | 169 (73 of them recall-guarded) |

The deterministic checks (`flag-exclusions`, `flag-gene-status`,
`fix-all-lineage`) found nothing left; `fix-genomic-notation` changed 1 trial.
