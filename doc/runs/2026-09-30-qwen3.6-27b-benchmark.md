# Benchmark: qwen3.6:27b on Ollama, and a failed gpt-oss:120b run (2026-09-30)

The first measurement of a self-hosted model on the current pipeline since
llama3.3:70b (2026-09-14). One replicate, so it can only show whether the
model is worth a proper comparison; it cannot settle one.

## Inputs
- **Model:** `qwen3.6:27b` (Ollama library build) on Ollama 0.34.0 under
  Singularity, one H100 NVL, 18.4 GB resident in VRAM. Temperature 0,
  seed 42, `top_k` 1, `num_ctx` 32768, `num_predict` 8192, thinking off, JSON
  schema through `format`.
- **Job:** Slurm 6752539 on the UZH cluster, `scripts/run_ollama_mapping.sh
  benchmark`. Its `runs/<run_id>/` (the run whose `run.json` names
  `qwen3.6:27b`) stays on the cluster checkout and is the only copy of the
  answers.
- **Trials:** the 56 curated benchmark trials (50 NCT, 6 CTIS), registry
  cache as on the cluster.
- **Scoring:** the job ran before a9aae13. Two defects made its own report
  unusable (below). The mapping was therefore rebuilt from the saved answers
  with `LLM_PLATFORM=Replay` at a9aae13, into
  `bench/output-qwen3.6-27b-replay/`. 56 of 56 trials were rebuilt with no
  replay misses, so every model answer is from the job; the code around it
  is a9aae13's, including the diagnosis-seed rules of 3736dd6.

## Defects found
1. **The benchmark dropped review-routed trials from the score.** They were
   written to `ctml/needs-review` and scored as MISSING OUTPUT: 7 of 56 in
   this job, which raised the means (the job's own NCT name F1 read 0.81 on
   43 trials, against 0.76 on all 50). Fixed in a9aae13.
2. **Concurrent jobs shared one output directory.** The old script wrote
   every model to `bench/output/` and `bench/report.json`. A gpt-oss job
   started while this one ran, so the `bench/report.json` committed in
   1ce15b4 mixed the two runs and was not a result for either; the next
   commit restores the file it replaced. Fixed in
   a9aae13 (`bench/output-<model>[-rep<N>]/`).
3. **gpt-oss:120b answered nothing.** The old code sent it `think: false`,
   which gpt-oss ignores. All 324 recorded calls (run
   `20260930T185930Z-983d21`) ended normally (`done_reason: stop`, ~81 tokens
   generated) with empty content and no thinking field. The reasoning was
   discarded and no answer followed. The job was cancelled. a9aae13 adds
   `OLLAMA_THINK`, and the script refuses gpt-oss with thinking off.
