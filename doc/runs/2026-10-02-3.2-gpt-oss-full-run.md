# First full mapping run with gpt-oss:120b (roadmap 3.2, 2026-10-02)

- **Date:** 2026-10-01 to 2026-10-02
- **Roadmap:** 3.2
- **Backend:** gpt-oss:120b on Ollama, the default since
  [../decisions/2026-10-01-gpt-oss-backend.md](../decisions/2026-10-01-gpt-oss-backend.md)

## Summary

All 1,137 in-scope cached trials were mapped with gpt-oss:120b on the pinned
weights, in two cluster runs: CTIS, then NCT. 11,118 model calls, none failed
and none empty; one was cut off at the output limit. 985 trials were published
and 152 went to review. The index has 938 mapped, 143 needs-review and 56
reviewed trials, with 0 layer conflicts. Every non-reviewed trial in it was
mapped by gpt-oss.

## Result
- **Coverage:** every in-scope trial has exactly one output.
  - CTIS: 277 of 331 cached records mapped.
  - NCT: 860 of 925 mapped; the other 65 are out of scope (supportive care,
    rollover studies and the like), listed in `ctml/out-of-scope.tsv`.
  - The output files match these counts one to one (242 + 35 CTIS, 743 + 117
    NCT), and every file was written by one of the two runs.
- **Calls:** 1,693 (CTIS) and 9,425 (NCT), 9.8 per trial. 0 errors, 0 empty
  answers. One call stopped at the 16,384-token output limit: the diagnosis
  call of NCT02332668, with 16,659 tokens generated. gpt-oss reasoned until
  the limit. The trial's own conditions seed its diagnoses, and it is a
  curated trial, so the index uses the reviewed copy.
- **Routing:** 985 published, 152 to review (13.4%). Review reasons were not
  tallied.
- **Index** (`utils.build_trial_index`): 1,137 trials, of which 938 are mapped,
  143 need review and 56 are reviewed. Also:
  - 108,462 diagnosis rows, 850 genomic rows, 55 protein changes (all
    verified against MANE), 0 layer conflicts, 0 review backups;
  - mapped with: `gpt-oss:120b genomic_prompt=roles;diagnosis_input=labelled`
    for 1,081 trials, and "unrecorded" for the 56 reviewed copies.
- **Trials without a diagnosis:** 25 are indexed with no diagnosis row, 18 of
  them CTIS. They can never be screened in. Whether all 25 are in the review
  queue was not checked; the first Haiku run had 26 such trials, all in review.

The trial counts differ by scope rules and cache, not by model. The genomic
rows and protein changes are roughly half the first Haiku run's. That run
predates the roles genomic prompt (2026-09-28), which by itself removed many
gene requirements (on the 370 labelled gene trials, those requiring a gene the
text does not require of every patient fell from 203 to 99). The 2026-09-28
run did not record its genomic row count. So the drop cannot be assigned to
the model from these numbers, and should be checked before relying on the
genomic layer.

## Defects found
1. **`map-all` mapped one day's NCT trials, not the corpus** (fixed in
   9f06aa0). `scripts/run_ollama_mapping.sh map-all` ran `main.py map --all`,
   which applies `MAPPING_CUTOFF_DAYS` (1, the nightly incremental setting).
   The first job's NCT run therefore skipped all 925 NCT trials as not
   recently updated. Only its CTIS run, which has no cutoff, mapped anything.
   `map-all` now passes `--cutoff-days 36500`; `CUTOFF_DAYS` and
   `SOURCE=nct|ctis` narrow it.
